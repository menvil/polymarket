# legacy-bot — материалы удалённого торгового приложения

> **Статус: архив. Не собирается, не тестируется, не является workspace-пакетом.**
>
> Само приложение `apps/bot` удалено после завершения Collector Qualification:
> его композиция не соответствует canonical event pipeline и будет написана
> заново. Здесь сохранено то, что переписывание кода **не воспроизводит**.

## Что здесь и зачем

| каталог | что это | зачем сохранено |
| --- | --- | --- |
| `docs/research/` | исследования: ablation-study, калибровка crowd, хвостовые зоны, оптимизация ценовой модели | результаты месяцев бэктестов; повторить дешевле нельзя |
| `docs/strategies/` | разборы стратегий: cex-lead-lag, adaptive-entry, selective-entry, paired-cex-crowd | логика и обоснования решений |
| `docs/guides/` | live-arb execution, exit-policy fallback, auto-redeem, unify paper/live | эксплуатационные уроки |
| `configs/` | 853 конфигурации бэктестов | **не настройки, а журнал перебора**: у каждой `_meta` с датасетом, результатом и заметками |
| `strategies/` | 33 реализации стратегий | референс формул и правил входа/выхода |
| `scripts/` | 37 скриптов анализа: edge-таблицы, sweep, сравнение paper/live, аудит live-vs-backtest | как считались приведённые в исследованиях числа |
| `live-account-reference/` | приватный контур live-рантайма: композиция, user-channel WS, приватные REST-клиенты и мапперы | вендорские контракты Polymarket и боевые граничные случаи маппинга — переписыванием не воспроизводятся ([README](./live-account-reference/README.md)) |

## Чем это НЕ является

Не библиотека и не точка расширения. Код здесь ссылается на удалённые пакеты
и **не скомпилируется** — он оставлен как текст для чтения, а не для запуска.
Новые стратегии пишутся под новый контракт заново; отсюда берутся идея,
формула и уже измеренный результат.

## Почему не просто «в истории git»

Для кода аргумент «git — архив» верен: его всё равно переписывать. Для
результатов исследований — нет: документ в истории найдёт только тот, кто уже
знает, что он существовал.
