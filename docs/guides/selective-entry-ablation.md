# SelectiveEntry: Ablation Study фильтров

> Дата: 2026-04-01
> Данные: 5-мин BTC Up/Down рынки, 4 дня (698 рынков total)
> btc1: 70, btc2: 254, btc4: 167, btc5: 207

## Описание стратегии

SelectiveEntry — buy-and-hold до settlement. Один раз решить (покупать или нет),
поставить limit BUY (maker) и держать до resolution. Без exit logic.

### Baseline-параметры

```json
{
  "orderSize": 5,
  "minZoneCents": 55, "maxZoneCents": 68,
  "minDeltaPct": 0.03, "maxDeltaPct": 0.12,
  "minTauSec": 120, "maxTauSec": 210,
  "maxSpreadCents": 4, "warmupSec": 60,
  "bidOffsetCents": 1
}
```

## Тестируемые сигналы

| Сигнал | Параметр | Описание |
|--------|----------|----------|
| **rise** | `minRiseCents: 3/5` | Momentum: EWMA растёт с момента warmup end |
| **zone60** | `minZoneCents: 60` | Строже нижняя граница зоны (60 вместо 55) |
| **wait40** | `waitPct: 0.4` | Ждём 40% жизни рынка (120s на 5-мин) вместо tau-фильтра |
| **comp5** | `compMaxDiscrepancyCents: 5` | UP+DOWN должны быть ≈100¢ |
| **daccel** | `requireDeltaAccel: true` | Delta растёт: BTC уходит от strike, не возвращается |

### Разница wait40 vs tau-фильтр

- **tau 120-210s**: вход разрешён только в узком окне (90s elapsed ÷ 180s elapsed)
- **waitPct=0.4**: вход разрешён после 120s elapsed и далее в любой момент (tau-фильтр отключён)

### Что такое delta acceleration

Delta = (BTC_price - strike) / strike × 100%.
DeltaAccel = delta_now - delta_at_warmup_end.

Если deltaAccel > 0 → BTC уходит от strike (тренд продолжается).
Если deltaAccel < 0 → BTC возвращается к strike (разворот, плохой сигнал).

### Наблюдения по комбинациям

1. **Комбинации не улучшают PnL vs daccel alone** (+24.71 > все комбинации)
2. **dw (daccel+wait40)** даёт лучший btc2 (+22.07!) но теряет на btc4/btc5
3. **rise всегда вредит** — dwr хуже всех комбинаций
4. **WR потолок на 5-мин BTC: ~68-69%**

## Выводы

### Рекомендации для production

| Цель | Конфигурация | WR | PnL |
|------|--------------|----|-----|
| **Максимальный PnL** | baseline + `requireDeltaAccel: true` | 68.3% | +24.71 |
| **Стабильность** | baseline + `waitPct: 0.4` (без tau) | 66.1% | +14.80 |
| **Агрессивный** | baseline + `requireDeltaAccel: true` + `waitPct: 0.4` | 68.1% | +20.42 |

### Почему 80% WR недостижим на 5-мин рынках

На 5-мин рынках BTC Up/Down:

- Шум цены BTC за 5 минут ≈ 0.1-0.3% — сравнимо с delta-порогами
- Price discovery длится ~60-120s, после чего рынок «залипает»
- Разрешение бинарное: даже при delta=+0.1% BTC может вернуться к strike

Для WR≥80% нужны **15-мин рынки** (AdaptiveEntry: 79.8% WR, +18.73 USDC).

## Bugfix'ы применённые перед ablation (2026-04-01)

1. **`_entered = true` перемещён после comp validation** — предотвращает permanent lockout
   при недоступности comp data
2. **Book fallback работает при `_tradeCount < 3`** — предотвращает зависание на рынках
   без tape trades (guard `_ewma === null` → `_tradeCount < 3`)

Bugfix'ы дали **идентичные результаты baseline** на текущих данных (156F, 65.6% WR, +13.75 USDC).
