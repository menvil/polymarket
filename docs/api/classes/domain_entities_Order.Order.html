    validate

    • validate(): void

      Validates order against business rules

      Returns void

      Throws

      If any validation rule fails

      Remarks

      Validates the following rules:

      1. ID must be non-empty string
      2. TokenId must be non-empty string
      3. Side must be 'BUY' or 'SELL'
      4. Status must be valid OrderStatus
      5. Size must be positive
      6. FilledSize (if present) cannot exceed original size
      7. AverageFillPrice must be valid if filledSize > 0
      8. Timestamp must be valid Date

      Example

      try {
        order.validate();
      } catch (error) {
        if (error instanceof OrderValidationError) {
          console.error(`Validation failed: ${error.message}`);
        }
      }

    canCancel

    • canCancel(): boolean

      Checks if order can be canceled

      Returns boolean

      True if order is PENDING or OPEN

      Remarks

      Only orders that are PENDING or OPEN can be canceled. FILLED, CANCELED, and REJECTED orders cannot be canceled.

      Business rule: Terminal states (FILLED, CANCELED, REJECTED) are immutable and cannot transition to other states.

      Example

      if (order.canCancel()) {
        await exchangeService.cancelOrder(order.id);
      } else {
        console.log('Order cannot be canceled');
      }

    • getNotional(): number

      Calculates the notional value of the order

      Returns number

      Notional value (price * size)

      Remarks

      Notional = Price × Size

      For BUY orders: This is the maximum amount needed to fill the order For SELL orders: This is the amount received if order fills

      Example:

      • Price: 0.65
      • Size: 100
      • Notional: 65.00

      Example

      const order = Order.create({
        id: '123',
        tokenId: 'token-yes',
        side: 'BUY',
        price: Price.fromNumber(0.65),
        size: Quantity.fromNumber(100),
        status: 'PENDING',
        timestamp: new Date()
      });

      const notional = order.getNotional();
      console.log(notional); // 65.0
