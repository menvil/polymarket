    Class CLOBClient

    CLOB REST API клиент

    Remarks

    Клиент для работы с Polymarket CLOB API. Автоматически подписывает все запросы приватным ключом. Использует HttpClient для всех HTTP запросов (retry, timeout, error handling).

      Получает список открытых ордеров пользователя

      Parameters

      • OptionaltokenId: string

        Опциональный фильтр по tokenId

      Returns Promise<PlaceOrderResponse[]>

      Массив открытых ордеров

      Throws

      При ошибке API или сети

      Remarks

      Возвращает только PENDING и OPEN (LIVE) ордера. FILLED и CANCELLED ордера не включаются в результат.

      Example

      // Все открытые ордера
      const allOrders = await client.getOrders();

      // Ордера для конкретного токена
      const tokenOrders = await client.getOrders('0x123...');
