    Class PolymarketWsClient

    PolymarketWsClient

    Remarks

    Чистый транспортный слой-обёртка вокруг WebSocketManager. Наследует EventEmitter для чистого event-based API.

    Принципы дизайна:

    1. Никакой domain логики: Только транспортные операции
    2. Пересылка событий: Прозрачная передача событий от WebSocketManager
    3. Защита timeout: Предотвращает зависание при переподключении
    4. Чистый API: Простой, сфокусированный интерфейс

    reconnectWithTimeout

    • reconnectWithTimeout(timeoutMs?: number): Promise<void>

      Переподключается с защитой timeout

      Parameters

      • timeoutMs: number = 10000

        Timeout в миллисекундах (по умолчанию: 10000)

      Returns Promise<void>

      Promise который разрешается при переподключении

      Throws

      Если клиент уничтожен

      Throws

      Если переподключение истекло по времени или не удалось

      Remarks

      Оборачивает reconnectForNewSubscription() в Promise.race с timeout. Предотвращает бесконечное зависание если переподключение застопорилось.

      Алгоритм:

      1. Создать timeout promise который отклоняется после timeoutMs
      2. Race timeout vs reconnectForNewSubscription()
      3. Если timeout победил → бросить timeout error
      4. Если reconnect победил → вернуть успех

      Example

      try {
        await client.reconnectWithTimeout(10000); // 10s timeout
      } catch (error) {
        console.error('Reconnect timeout:', error);
      }
