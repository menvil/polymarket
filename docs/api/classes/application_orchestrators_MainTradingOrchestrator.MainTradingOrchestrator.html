    Class MainTradingOrchestrator

    Main Trading Orchestrator

    Remarks

    Координирует весь trading flow. Single point of control для всей торговой логики.

    ВАЖНО: Polymarket использует два отдельных токена (YES и NO) для каждого рынка. Orchestrator подписывается на оба токена и агрегирует данные.

    getLastRiskAssessments

    • getLastRiskAssessments(): [RiskAssessment | null, RiskAssessment | null]

      Возвращает последнюю оценку риска (4-layer)

      Returns [RiskAssessment | null, RiskAssessment | null]

      RiskAssessment или null если ещё не было оценки

      Remarks

      Содержит полную информацию из 4-layer decision system:

      • Layer 0: Edge status (alive/warning/dead)
      • Layer 1: Signals (fragility, refill rate, market state)
      • Layer 2: Risk (status, mode, urgency)
      • Position and time info

      Example

      const assessment = orchestrator.getLastRiskAssessment();
      if (assessment) {
        console.log(`Mode: ${assessment.mode}, Edge: ${assessment.edgeAlive}`);
      }

      Remarks

      Выполняет сверку:

      • Баланса USDC
      • Позиций по токенам
      • Статусов активных ордеров

      При обнаружении расхождений логирует предупреждения. Если autoCorrect=true, автоматически исправляет расхождения.

      Example

      if (result?.hasDiscrepancies) {
        console.warn('Found discrepancies:', result.discrepancies);
      }
