    • getOrderbook(marketId: string): Promise<ApiOrderbook>

      Получает orderbook для рынка

      Parameters

      • marketId: string

        ID рынка (token ID)

      Returns Promise<ApiOrderbook>

      API orderbook

      Throws

      При ошибке API или timeout

      Remarks

      Алгоритм:

      1. Вызывает GET /book/{marketId}
      2. Парсит JSON response
      3. Возвращает ApiOrderbook

      NOTE: Текущая реализация возвращает mock данные. В production нужен реальный API endpoint.

      API endpoint format:

      • URL: /book/{tokenId}
      • Method: GET
      • Response: { asset_id, market, bids, asks, timestamp }

      Example

      try {
        const orderbook = await client.getOrderbook('0xabc123');
        console.log(`Best bid: ${orderbook.bids[0].price}`);
      } catch (error) {
        if (error instanceof HttpError) {
          console.error(`HTTP ${error.status}: ${error.message}`);
        }
      }
