      Статистика воспроизведения

      Throws

      Если воспроизведение было прервано (signal.abort())

      Remarks

      Обрабатывает события последовательно (backpressure). Ошибки в eventHandler логируются, но не останавливают воспроизведение. onFileComplete вызывается после обработки всех событий из каждого файла.

      Example

      const abortController = new AbortController();

      // Graceful shutdown
      process.on('SIGINT', () => abortController.abort());

      try {
        const stats = await runner.run(
          async (event) => { ... },
          async () => { await pipeline.finalizeFile(); },
          abortController.signal
        );
      } catch (error) {
        if (error.message === 'Aborted') {
          console.log('Replay stopped gracefully');
        }
      }
