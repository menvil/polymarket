      Remarks

      Validates that bid <= ask. In prediction markets:

      • Bid is the highest price buyers are willing to pay
      • Ask is the lowest price sellers are willing to accept
      • Ask must be >= bid (no crossed markets)

      const ask = Price.fromNumber(0.52);

    • tighten(amount: number): Spread

      Tightens spread by moving bid/ask closer

      Parameters

      • amount: number

        Amount to tighten (reduce width by 2x this amount)

      Returns Spread

      New Spread with tightened width

      Remarks

      Moves bid up and ask down by the specified amount. Useful for market making strategies. If amount would cross the spread, returns zero-width spread at midpoint.

      console.log(tightened.width()); // 0.02
