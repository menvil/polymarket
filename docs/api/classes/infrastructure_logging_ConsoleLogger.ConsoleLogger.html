    child

    • child(context: string): ILogger

      Создаёт дочерний логгер с контекстом

      Parameters

      • context: string

        Контекст (например, имя сервиса/модуля)

      Returns ILogger

      Новый логгер с добавленным контекстом

      Remarks

      Дочерний логгер наследует конфигурацию родителя. Все сообщения будут включать указанный контекст.

      Example

      const logger = new ConsoleLogger();
      const mmLogger = logger.child('MarketMaker');
      const riskLogger = logger.child('RiskManager');

      mmLogger.info('Started'); // [INFO] [MarketMaker] Started
      riskLogger.warn('Limit exceeded'); // [WARN] [RiskManager] Limit exceeded

      Implementation of ILogger.child
