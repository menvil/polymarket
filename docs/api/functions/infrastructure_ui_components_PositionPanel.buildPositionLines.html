    Function buildPositionLines

    • buildPositionLines(data: StatusDisplayData, _config: UIConfig): string[]

      Builds formatted position lines for display

      Parameters

      • data: StatusDisplayData

        Status data with position info

      • _config: UIConfig

      Returns string[]

      Array of formatted lines

      Remarks

      Displays:

      • Current positions (YES, NO, net)
      • PnL breakdown (unrealized, realized, total)
      • Cash balances (available, reserved)
      • Portfolio value (if applicable)

      Example

      const lines = buildPositionLines({
        yesPosition: 10.5,
        noPosition: 5.2,
        netPosition: 5.3,
        unrealizedPnL: 12.50,
        realizedPnL: -3.25,
        totalPnL: 9.25,
        cash: 9500,
        reservedCash: 150,
        // ... other fields
      }, { asciiOnly: true });
